# 现场阅读 HTML

## 写作与页面层次

主讲内容在语义上完整，再做页面。颜色不是叙事策略：

- 普通口播：与非口播提示区分，正常强调字重。
- 核心判断与取舍：用字重与强调样式标记，少量选择完整判断或关键短语。
- 状态、风险条件、投入门槛：使用另一种强调样式。
- 讲述路标：灰色小标题，不朗读。
- 操作提示：浅黄色，与口播分开。
- 可选深入：紧跟对应段落，不在整章转场之后；可展开继续讲。

不在网页界面展示 JSON、来源哈希或模型工作过程。需要版本或来源备注时用简短准备说明，不混入口播。按用户偏好调整颜色，但保留字重与标签等非颜色线索。

## 渲染器输入

创建 UTF-8 JSON，结构如下。示例只解释结构，不代表某个产品事实：

```json
{
  "title": "阶段汇报",
  "language": "zh-CN",
  "palette": "classic",
  "subtitle": "熟悉产品的评审团队 · 决策讨论",
  "chapters": [
    {
      "id": "decision",
      "title": "本次结论与待决策事项",
      "seconds": 90,
      "claim": "先说明本次变化，再进入依据",
      "blocks": [
        {
          "id": "opening",
          "label": "本次判断",
          "cue": "看向决策者，说完结论停顿。",
          "text": "本次优先讨论质量验证的安排。\n\n具体执行范围需要今天共同确认。",
          "emphasis": [
            {"text": "本次优先讨论质量验证的安排。", "kind": "key"},
            {"text": "具体执行范围需要今天共同确认。", "kind": "boundary"}
          ],
          "depth": [
            {
              "label": "为什么先讨论范围",
              "text": "这里补充与上文相关的解释，结束后接下一论点。"
            }
          ]
        }
      ],
      "transition": "下面说明支持这个判断的依据。"
    }
  ]
}
```

字段规则：

- title、chapters 必填。subtitle 可选，纯文本。
- language 为可选语言标签，默认 zh-CN 保持兼容。中文标签使用中文界面；其他标签使用英文界面，口播内容不自动翻译。生成时按用户语言设置此字段。
- palette 可选 classic（默认多色）或 monochrome（单色，以字重、下划线和边框区分语义）。颜色是默认阅读方案，不是固定品牌要求。
- chapter.id 与 block.id 使用字母开头的英文小写、数字、连字符，全局唯一。
- title、seconds、blocks 为章节必填。seconds 为正整数、仅代表主讲预算；可选展开与问答另计。
- block.text 为完整可讲的纯文本，以两个换行分段。不要塞入 HTML 或 Markdown。
- block.label、cue 可选，明确不朗读。transition 可选，为口播。
- emphasis 是可选数组，text 必须是本 block.text 的原样子串。kind 只能为 key 或 boundary。不可重叠。对子串所有出现位置标记，所以宜选择有辨识度的完整短语。
- depth 是可选数组，直接隶属相应 block；label、text 必填，也可有 emphasis。不要把全章深度塞进最后一个 block。
- 要在一段解释中间展开时，将主讲切成两个 blocks，绑定在前一个之后，保持文字顺序不变。

## 命令

```sh
python3 <skill-dir>/scripts/render_speaker_html.py --input work/talk.json --output outputs/讲稿.html
```

标准库即可运行。内容全部转义，HTML 自包含；不引用外部字体、媒体、接口或用户文件绝对路径。章节数、导航与计时预算从输入计算，无固定产品名、章数、时长。

## 检查

先检查正文、字段与展开位置，再运行渲染器。检查生成文件的章节和展开数量、时间、HTML ID、口播保真，以及重点是否过密。有授权且允许的预览能力时检查桌面与窄屏、深色模式、字号、计时和导航。浏览器安全策略禁止本地文件时不要绕过；继续允许的静态检查并说明未完成视觉验证。

不自动重写源页面或发布讲稿；文件保存路径遵循当前会话规则。演讲者稿可能含内部信息，仅按用户授权分享。
